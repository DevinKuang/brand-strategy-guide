## 附录：案例匹配引擎算法

```
输入：用户行业 + 品类 + 品牌阶段 + 团队规模 + 预算量级 + 定位方法（如已确定）
输出：主推×1 + 辅助×2 + 索引列表

Step 1 · 硬过滤
  ├─ 排除与品牌定位方法矛盾的案例（如品牌走情感价值型，排除竞品对立型案例）
  ├─ 排除团队规模差距过大的案例（如1人团队排除蔚来NIO House级案例）
  └─ 排除预算量级差距2档以上的案例（如<50万预算排除瑞幸×茅台级联名）

Step 2 · 多维打分
  每个候选案例在 4 个维度上打分（1-5分）：
  ├─ 行业匹配度：同行业=5 / 相邻行业=3-4 / 跨行业=1-2
  ├─ 情境相似度：品牌阶段+团队规模+预算量级的综合相似度
  ├─ 痛点匹配度：核心挑战的相似度（从案例"匹配标签"和用户描述中判断）
  └─ 学习价值度：案例方法论的可迁移性

Step 3 · 排序输出
  ├─ 总分最高 → 主推案例（深度展开）
  ├─ 总分第2-3 → 辅助参考（简要展开）
  └─ 其余 → 案例库索引（品牌名+一行洞察）
```
