# 品牌全案策略 · 创始人 Brief

> **这份文档是什么**：你在品牌策略上的全部"已知信息"和"主观判断"。
> **Skill 做什么**：基于你提供的信息，搜索验证、补充数据、做竞争分析和用户洞察，然后给你判断和选择——而不是替你填空。
>
> **填写原则**：
> - **只写你知道的、你相信的、你观察到的**。不知道的写"不确定"，Skill 会去搜。
> - **不要为了填满而编数据**。市场规模、增速这些让 Skill 来搜。
> - **你的主观判断最有价值**——"我觉得竞品 A 的产品其实不如它的包装"比"竞品 A 年营收 5000 万"对 Skill 更有用。
> - **用口语写**。你的原话是最好的原材料。

---

## §1. 你对这个行业的判断

> Skill 会搜索市场规模、增速、趋势。你不需要提供这些数据。你只需要告诉我：你在行业里看到了什么、你觉得哪里不对、你认为机会在哪。

### 1.1 你看到的

```
- 这个行业现在最让你兴奋的变化是什么？
- 你觉得这个行业最不合理/最让你不满意的地方是什么？
- 你有没有观察到什么"大家都这么说，但你觉得不对"的现象？
```

（在此填写）

### 1.2 你觉得机会在哪

```
- 你认为市场上有什么需求是"明明存在但没人认真做"的？
- 如果只让你押注一个趋势，你押什么？
```

（在此填写）

---

## §2. 你对竞争的看法

> Skill 会搜索竞品数据、做全景矩阵。你只需要提供你知道的竞品和你对他们的主观判断。

### 2.1 你眼中的竞品

```
- 列举你知道的竞品（2-5 个就行，说品牌名）
- 他们各自做得最好的是什么？（可以是产品、包装、内容、社群……任何维度）
- 他们各自做得最差/让你觉得"有缺口"的是什么？
- 有没有哪个竞品你研究过之后觉得"他们其实没那么强"？为什么？
```

（在此填写）

### 2.2 你的差异化直觉

```
- 如果用一句话说你和他们最大的不同，是什么？
- 你觉得这个不同是"竞品做不了"还是"竞品不想做"？
```

（在此填写）

---

## §3. 你对你用户的了解

> Skill 会搜索用户数据、做画像和旅程地图。你不需要提供人口统计数据。你只需要告诉我：你接触过的用户是什么样的人、他们跟你说过什么、你观察到了什么。

### 3.1 你接触过的用户

```
- 描述 1-2 个你接触过的真实用户（不用真名）：
  · 他/她是什么样的人（年龄/职业/生活方式，大概就行）
  · 他/她在什么场景下遇到了什么问题
  · 他/她现在怎么解决
  · 他/她说过什么让你印象深刻的话（尽量保留原话）
```

（在此填写）

### 3.2 你观察到的用户行为

```
- 你觉得用户在购买/使用这个品类的产品时，最让你意外的一个行为是什么？
- 用户在做购买决策时，你观察到他们最依赖什么信息来源？
- 你觉得用户"嘴上说的需求"和"真正在意的"之间有没有差距？是什么？
```

（在此填写）

## §4. 你自己的情况

### 4.1 团队

```
- 创始人背景（之前做什么的、最擅长什么）
- 团队目前几个人、分别负责什么
- 有没有关键岗位还缺人的？缺什么？
- 团队有什么"别人抄不走的"能力或资源？
```

（在此填写）

### 4.2 你的优势和短板

```
- 如果现在有另一个团队做一模一样的事，你凭什么做得比他们好？
- 你最担心自己做不好的是什么？
```

（在此填写）

### 4.3 品牌现状

```
- 品牌名叫什么（有的话）？怎么来的？有什么寓意？
- 品牌在什么阶段：想法 / 原型 / 已经在卖了？
- 如果在卖了：卖得怎么样？（不用精确数字，大致感受就行）
```

（在此填写）

## §5. 预算和资源

```
- 启动资金量级（<50万 / 50-300万 / >300万）
- 资金到位了吗，还是需要融资？
- 手上已经有的是什么（商标/产品/客户群/自媒体账号/供应链/渠道关系/合作伙伴……）
- 如果预算有限，你倾向于先投产品打磨还是先投市场推广？
```

（在此填写）

## §6. 你想要的品牌

### 6.1 动机和愿景

```
- 是什么让你决定做这件事？（一个具体的瞬间或经历，不是"看到了市场机会"）
- 如果这个品牌 5 年后在用户的生活中扮演一个角色，你希望那个角色是什么？
- 做这件事的过程中，有没有什么是"再赚钱你也不会做"的？
- 如果你要在 30 秒内向一个陌生人解释你为什么做这件事，你会怎么说？
```

（在此填写）

### 6.2 你的审美和品味

```
- 列举 3-5 个你欣赏的品牌（不限行业）。每个品牌说一句：你喜欢它什么。
- 有没有什么视觉风格/颜色/质感是你特别想靠近或特别想避开的？
```

（在此填写）

### 6.3 你对产品的设想

```
- 你理想中第一个产品是什么样的？（形态/体验/包装/定价感觉）
- 你觉得你的产品"最让用户惊喜"的瞬间应该发生在他/她用的哪个环节？
```

（在此填写）

### 6.4 你对内容传播的想法

```
- 你觉得自己擅长哪种表达方式（写文章/拍视频/做播客/直播/都不擅长）？
- 你愿意自己出镜或写东西吗？还是希望品牌独立发声？
- 你觉得你的品牌应该"怎么跟用户说话"？（像一个懂行的朋友/像一个幽默的段子手/像一个默默守护的人/……）
```

（在此填写）

### 6.5 战略方向

```
- 你希望品牌第一年做到的最重要的一件事情是什么？（只选一件）
- 你觉得品牌从 0 到 1 这个阶段，最应该集中精力做什么？最不应该分散精力做什么？
- 你有没有正在"主动拒绝"的机会或方向？为什么拒绝？
- 如果只剩 6 个月的时间和钱，你会停掉什么？留下什么？
```

（在此填写）

## §7. 你的深层判断

> 以下问题没有标准答案。它们捕捉的是你作为创始人的直觉、担忧、信念——那些数据无法告诉你、但会深刻影响品牌方向的东西。

### 7.1 对品类的深层直觉

```
- 这个行业有没有什么"大家都知道但没人说"的问题？
- 你觉得这个品类里，用户"一直在忍受但已经放弃抱怨"的是什么？
- 如果 3 年后这个品类被彻底颠覆，你觉得最可能是因为什么？
- 有没有一个"外行人不懂、但从业者心知肚明"的行业秘密或潜规则？
```

（在此填写）

### 7.2 对竞争的真实恐惧

```
- 你真正害怕的竞争对手是谁？（不一定是你前面列的那几个）
- 那个对手如果决定进入你的赛道，它做哪一件事就能对你造成最大威胁？
- 反过来，它为什么可能不会这么做？（结构性原因，不是"他们没眼光"）
- 你觉得你的品牌有什么"被对手模仿了就很难受、但对手就是模仿不了"的东西？
```

（在此填写）

### 7.3 对用户不可见的需求

```
- 用户从来没有主动问过、但你觉得他们其实需要的是什么？
- 你有没有观察到用户在"用你的品类"时的一个奇怪行为或土办法？
- 如果你的用户只能从你的产品中得到一种"感觉"，你希望那是什么感觉？
- 你见过用户在使用竞品时"最心酸"的一个瞬间是什么？
```

（在此填写）

### 7.4 对产品的偏执

```
- 产品里有没有一个细节，你花了远超外人想象的精力？是什么？为什么较这个劲？
- 有没有用户强烈要求但你坚决不做的功能/特性？为什么不做？
- 你觉得"好产品"和"够用的产品"之间，那条线画在哪？
```

（在此填写）

### 7.5 对品牌的信念

```
- 如果有一天你的品牌"变味了"，你觉得最可能是因为做了什么（或没做什么）？
- 你希望用户在向朋友推荐你的时候，用的那句话是什么？（不是广告语，是他/她自己的话）
- 你最不想被拿来比较的品牌是谁？为什么？
- 如果品牌是一个人，在社交场合别人介绍他/她时，你觉得第一句话应该是什么？
```

（在此填写）

### 7.6 你的不确定

```
- 关于这个品牌，你现在最拿不准的一件事是什么？
- 有没有一个假设，如果被证明是错的，你的整个方向就需要调整？
- 你身边有没有一个"最诚实的批评者"（敢跟你说真话的人）？他/她觉得你这个想法最大的风险是什么？
```

（在此填写）

## 填写完成后

将本文件保存为 `output/brief.md`，在对话中说"用 brief 模式"，Skill 会：
1. 读取你的判断和洞察
2. 搜索补充行业数据、竞品信息、用户行为数据
3. 把搜索结论和你的判断做交叉验证——一致的采纳，矛盾的交给你判断
4. 推给你策略选项让你选择（定位方法、原型、定价策略等）
5. 输出完整方案
