## 2. 阶段一：差异化验证

### 2.1 搜索验证清单

| 验证对象 | 搜索关键词 | 目的 |
|----------|-----------|------|
| 差异化声明 | `"[差异化关键词]" 品牌 " + brief 中的差异化描述关键短语` | 验证是否有竞品已在用类似定位 |
| 品牌现状 | `"[品牌名]" 评价 知乎`、`"[品牌名]" 小红书` | 对比六维自评分与外部真实口碑 |
| 对标品牌 | 对 brief §6.5 列出的每个对标品牌：`"[对标品牌]" 品牌定位 策略"` | 分析对标品牌是否适合作为参考系 |
| 创始人信息 | `"[创始人姓名]" "[品牌名]" 创始人` | 验证创始人公开信息与 brief 一致性 |

### 2.2 重点验证项

- **差异化唯一性**: brief 声称的差异化，搜索是否有竞品已在做（或已放弃做）
- **六维诊断校准**: 自评分数 vs 外部口碑，偏差超过 2 分则标注下调建议
- **对标合理性**: 对标品牌与自身资源是否匹配（对标爱马仕但预算 50 万 = 不合理）
- **创始人叙事一致性**: 创始人公开言论与 brief 动机描述是否一致
- **对话原材料核对**: 如果 strategy_premise.md 存在，逐条核对 premise 中的定位/使命/愿景/价值观方向与 Agent A 生态位是否一致

## 3. 阶段二：内容生成

**核心原则**: Agent B 的战略定位不是"创始人想成为什么"，而是"生态位需要什么身份来占据"。brief/strategy_premise 的创始人动机是原材料，Agent A 的生态位判断是过滤器，B 的输出是被过滤器加工后的成品。

### 必须遵守的输出规范
- **一致性铁律**: 模块 9 的定位方法 → 模块 10 的定位语 → 模块 12 的原型选择 → 模块 13 的品牌故事 → 模块 16 的视觉方向，必须形成一条可追溯的逻辑链
- **所有结论必须有推导过程**: 不只要"是什么"，更要"为什么是这个而不是那个"
- **案例分析**: 每个模块至少 1 个对标案例（正例或反例），含品牌名+具体做法+数据+对本品牌的迁移启示
- **页数标准**: 以下每个模块至少独立成 1 页。数据/案例密集模块必须拆为 2-5 页。两个不同模块不得共享一页

### 模块清单

#### 模块 9：品牌定位方法选择与推导（2-3 页）

**第 1 页｜从生态位到定位方法**
- 回顾 Agent A 的生态位判断（目标人群 + 差异化空间 + 竞争空白）
- 生态位→定位方法推导链路图（内联 SVG 流程图）
- 四问决策树可视化，每一步标注"第X问：[判断结果]"
- 右下角标注 `[参考: 指南2.0 二-2.1 定位方法选择决策树]`

**第 2 页｜四种方法对比 + 推荐方案**
- 四方法对比雷达图（内联 SVG，四轴：差异化壁垒/教育成本/受众规模/情感粘性）
- 对比表格（方法名称/适用条件/风险/同类案例）
- 推荐结论：推荐方法 + 一句话解释为什么其他三种不选
- 从 4 种定位方法中选定 1 种：品类占位型 / 竞争对立型 / 情感价值型 / 价值主张型

**第 3 页｜相似定位成功案例**
- 案例品牌 logo + 一句话定位语 + 关键数据
